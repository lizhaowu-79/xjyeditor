XJY Editor 帮助

XJY Editor 在浏览器中查看和编辑 XML、JSON、YAML 文档，另有 CSV、SQLite、Excel 三个数据编辑器。本页说明各项功能、保存方式和使用限制。

快速上手

  1. 打开 XJY Editor，点击「打开文件」选择 .xml、.json 或 .yaml 文件；也可以先点「XML 示例」等按钮体验。
  2. 左侧目录树选择节点，右侧修改名称、值或属性；进入容器后可在「智能表格」中成批编辑同级节点。
  3. 修改完成后点击「保存」或按 Ctrl+S。保存时保留原文件的编码和换行符，详见保存、草稿与导出。

页头的「CSV 编辑器」「SQLite 编辑器」「Excel 编辑器」在新标签页中打开对应的数据编辑器，当前编辑内容不受影响。

文件只在你的浏览器中处理，不上传到服务器；例外情况见隐私与数据。

打开文件与编码

点击「打开文件」选择本机文件。格式按扩展名判断：.xml、.json、.yaml / .yml。

编码识别

  • 文件带 BOM 时按 BOM 识别（UTF-8、UTF-16 LE / BE）。
  • XML 声明中写明的编码（如 encoding="GBK"）会被采用。
  • 其余文件先按严格 UTF-8 读取。
  • 都无法确定时会弹出「选择文件编码」窗口：下拉选择编码，下方预览实时显示读取效果，确认文字正常后再打开。中文界面默认建议 GB18030，英文界面默认建议 Windows-1252。

看起来是二进制内容的文件不会被打开。打开后，页面底部的文件状态行显示关联的文件名、编码和换行符，例如「关联文件：data.xml · GB18030 · CRLF」。

语法错误

文件有语法错误时，内容进入源码修复流程：在「源码」页修改并点击「应用源码」，修复前不能使用树和表格编辑。「✓ 语法校验」可随时检查当前文档或未应用的源码。

浏览与编辑节点

单节点编辑

在左侧目录树选择节点，右侧可修改名称、类型、属性或值；输入完成后移出焦点即应用。节点可以添加、复制、上移 / 下移、移动和删除，也可以在目录树和表格中拖动调整顺序。

导航

  • Alt+← / Alt+→ 后退 / 前进，Alt+↑ 进入父节点。
  • Ctrl+K 聚焦搜索框，可搜索名称、值、属性或显示路径，点击结果会展开并定位节点。
  • 目录树与源码双向定位：在源码中移动光标会选中对应节点，反之亦然。

源码

「〈〉源码」页可直接编辑文本。修改后点击「应用源码」才会更新节点；未应用时暂停定位和节点比较。「⇥ 格式化」按两空格缩进重新排版，可撤销。

更多工具

「⧉ 重复检查」列出 XML 中完全相同的同级元素（只提示，不修改）。此外还有条件查询、检查点、批量预览、模板以及 Schema 子集校验。

智能表格

进入一个容器节点后，「▦ 智能表格」把它的同级子节点显示为表格：XML 的属性和简单子元素、JSON / YAML 的字段各成一列。按 Enter 应用单元格；带子树的字段可以继续进入。

  • 首列复选框支持多选，「全选筛选结果」「清除选择」用于批量操作。
  • 筛选后，结构相同的记录会重新识别为属性列。
  • 在编辑框内拖动是选择文字，不会移动行。
  • 同一列中做相似的修改可触发辅助编辑。

辅助编辑

辅助编辑把你在几个单元格中做的相同修改，批量应用到同一列的其他单元格。XJY Editor 和 CSV、SQLite、Excel 编辑器都支持。

自动识别

在同一列中，对三个不同的记录连续做相似的插入或删除（例如都删掉开头的 PRE_），第三次提交后会弹出预览，列出将要修改的其余单元格。

主动发起

点击「辅助编辑」，或右键单元格选择「辅助编辑此列…」，自行指定列、规则、内容和位置。Shift+右键保留浏览器自己的菜单。

规则与范围

  • 系统按优先级匹配规则：完全一致 → 忽略大小写 → 等长同模式 → 仅等长。下拉列表可以改选其他兼容规则，也可以恢复初始规则。
  • 结束位置从右侧计数；字符按 Unicode 码点计数。
  • 范围默认为当前筛选结果，可明确切换到当前目录的全部记录。
  • 自动模式不会重复处理你手动修改的那三项。

检查预览后点击确认才写入；整批修改可以一次撤销。

保存、草稿与导出

保存

每个编辑器都只有一个「保存」按钮（Ctrl+S）。保存按打开时的编码、BOM 和换行符写出文件。是否能直接写回原文件，取决于浏览器和打开方式：

情况保存结果
Edge 或 Chrome，通过 HTTPS 或本机地址访问，用「打开文件」打开 直接写回原文件。第一次保存时浏览器会询问是否允许修改该文件。
通过本机助手右键打开直接写回原文件。
其他浏览器、通过普通 HTTP 访问、离线版，或打开的是示例 下载一个同名文件，下载即视为已保存。

页面底部的文件状态行会说明当前属于哪种情况：「关联文件：…」表示写回原文件，「保存时下载 · …」表示下载。

保存时的提示

  • 文件已被其他程序修改：打开后磁盘上的文件又被改过时，保存前会询问是否覆盖。
  • 换行符混用：文件中同时有 CRLF 和 LF 时，保存会统一为一种，先询问是否继续。
  • 字符无法用原编码保存：例如在 GBK 文件中输入了 emoji，会列出出问题的行，文件不会被写出。请修改这些字符后再保存。

源码草稿

源码页有未应用的修改时，按钮显示为「保存源码」，保存的是源码文本本身，不会自动应用到节点。CSV 和 Excel 编辑器则要求先应用或放弃源码草稿。

本地草稿

「保存本地草稿」「恢复草稿」把内容存在浏览器本地，用于意外关闭后的恢复，不能代替保存文件。草稿属于当前网址，换一个网址或使用离线版时互不相通。

导出

「↓ 导出文件」（XJY Editor）以及表格编辑器中的「导出 CSV…」「导出数据库…」「导出工作簿…」下载一份新文件，不影响原文件，也不清除未保存标记。

转换并导出

「转换并导出…」把正在编辑的内容转换成另一种格式并下载新文件，当前文档保持不变。

编辑器转换内容可转换为
XJY Editor当前整个文档（包括未应用的源码）XML、JSON、YAML 中的另两种
CSV当前整个表格，包括筛选隐藏的记录XLSX、TSV、CSV（可改编码）
Excel当前工作表的完整使用范围CSV、TSV
SQLite当前表的全部记录CSV、TSV、XLSX

转换前会显示预览和会发生的变化，例如 XML 转 JSON 时注释会丢失、属性写成 @名称。需要勾选「我已了解以上转换规则和内容变化」后才能导出。

会被拒绝的情况

  • XML 中有 DTD，或转换后的元素名、属性名不合法。
  • YAML 使用锚点 / 别名、自定义标签或多文档。
  • 有重复键，或嵌套超过 200 层。
  • 表格超过 100 万个单元格，或超出 Excel 的行列限制。
  • 目标编码无法表示其中的字符。

与 FindChanged 比较

比较两个节点

  1. 在智能表格中勾选恰好两个同级节点，点击「比较选中两项」。
  2. 确认左右顺序（可交换），点击底部「打开 FindChanged」。
  3. FindChanged 在新标签页中显示两个子树的差异。

在 FindChanged 中点击差异可以回到 XJY Editor 定位：共有的差异回到右侧节点，左侧独有的差异回到左侧节点。来源内容改动后需要重新比较。

比较整个文件

「交给 FindChanged」可以比较基线、当前内容或另一个文档的完整文件。

FindChanged 中的修改不会写回 XJY Editor。XML 只能比较元素；YAML 引用和受保护结构暂不支持比较。每侧最多 5 MiB、10 万行，超出时只提供文件下载。

CSV 编辑器

打开或拖入 .csv、.tsv、.txt 文件，在「解析设置」中确认编码、分隔符和是否把首行作为表头。

  • 支持逗号、分号、制表符分隔；编码支持 UTF-8、UTF-16 和 GB18030，识别不了时需要你手动选择并预览。
  • 所有字段按文本处理：前导零、长数字、日期和空格都按原样保留。
  • 双击单元格在格内编辑：Enter 确认，Shift+Enter 换行，Esc 取消。可插入 / 删除行列、改表头、粘贴矩形区域。
  • 拖动或 Shift 扩选、Ctrl 多选；复制为制表符分隔文本，可直接粘贴到 Excel。
  • 查找、按列筛选、在选区或全表中替换，替换前有预览。
  • 「源码」页直接编辑 CSV 文本，点击「应用源码」后更新表格。

保存时只改动编辑过的记录，其余记录、编码和换行符保持原样。删除整列会连同筛选隐藏的数据一起删除，确认窗口会提示。

SQLite 编辑器

打开 .sqlite、.sqlite3、.db、.db3 数据库文件，左侧选择表或视图，表格每页 100 条，支持多条件组合筛选（包含、不包含、比较运算符、NULL 与空文本判断）和列头点击排序。

  • 双击字段编辑，并明确选择写入类型：文本、整数、实数、NULL 或 BLOB（十六进制）。整数按 64 位精确处理，不会被舍入。
  • 二进制（BLOB）预览与文件导入导出：自动识别 PNG、JPEG、GIF、WebP、BMP、ICO、SVG 等图像及 PDF、ZIP、GZIP、JSON、XML 等格式；图像直接在单元格内显示缩略图与尺寸，点击可打开三视图窗口（大图预览、Hex + ASCII 对照、UTF-8 文本），并支持把本地文件直接导入为 BLOB 或按识别扩展名导出文件。
  • 可添加记录（使用默认值和自动主键）和删除多行。数据库自身的约束、外键和触发器照常生效，失败时整个操作回退。
  • 导入 CSV：可将 CSV / TSV 导入为新表或追加到已有表，自动识别编码与分隔符、推断字段类型并逐列调整，一步撤销。
  • 结构页：列出数据表、视图、索引与触发器及建表 SQL；支持新建/修改/删除表（优先使用 ALTER TABLE，需要时自动重建表并保留数据、索引、触发器与自增序号）和新建/删除索引。
  • SQL页：支持执行全部（Ctrl+Enter）、执行光标所在语句（Shift+Enter）或选中语句；只读查询不产生修改历史，含写入的整批作为一个事务和一步撤销，每个结果集最多显示前 1000 行。

只读与限制

  • 视图、虚拟表、系统表、生成列，以及无法唯一定位记录的表不在数据页直接编辑。
  • WAL 模式的数据库只允许查询：请先在原应用中关闭数据库（完成检查点）再修改。
  • 已有外键错误的数据库在数据页拒绝修改，可在「SQL」页修复外键问题（不允许产生新的外键错误）。

保存写出整个数据库文件。暂不支持打开加密数据库。

Excel 编辑器

打开 .xlsx 工作簿，切换工作表、翻页、按地址定位和筛选。隐藏的行列默认不显示，可以选择显示。

  • 双击单元格编辑，可写入文本、数值、布尔、日期、公式或错误值。文本 001 会保留前导零。
  • 粘贴制表符分隔文本前会确认，内容一律按文本写入。
  • 「源码」页可编辑当前工作表的 XML，只允许修改已有单元格的值和公式。

保存时只修改目标工作表，原有样式、图表、其他工作表都保留。浏览器不计算公式：修改后公式标为「待重算」，请在 Excel 中打开保存后的文件完成重算。

限制

  • .xls 旧格式只能查看和复制，不能保存；请先在 Excel 中另存为 .xlsx。
  • 受保护的工作表、含宏或签名的工作簿只读；合并区域只能改左上角；共享公式和数组公式区域只读。
  • 不能插入 / 删除整行整列、修改格式或工作表名。
  • 工作簿最大 30 MB，解压后最大 100 MB；单元格文本最多 32767 个字符。不支持加密工作簿。

本机助手（右键打开）

XJY Editor 助手是一个 Windows 小程序。安装后，在资源管理器中右键文件，选择「用 XJY Editor 打开」，即可在浏览器中打开该文件，保存时直接写回原文件。

  • 支持 .xml、.json、.yaml、.csv、.tsv、.sqlite、.sqlite3、.db、.db3、.xlsx、.xls，按格式进入对应的编辑器。
  • Windows 11 中菜单可能在「显示更多选项」里。只对单个文件显示，多选或文件夹不显示。
  • 双击 XJYEditorHelper.exe 安装，不需要管理员权限，也不改变文件的默认打开程序。再次双击安装目录中的助手，或在 Windows「设置 → 应用」中卸载。
  • 助手只在本机 127.0.0.1 上工作，只能访问你选中的那一个文件；文件内容不经过网站服务器。单个文件最大 128 MiB。
  • 页面停止使用 10 分钟后助手自动退出；刷新页面后不会自动重新关联文件，需要右键重新打开。

CSV、SQLite、Excel 文件的直接写回需要助手 0.3.0 或更新版本；旧版本保存时会改为下载。

隐私与数据

  • 文件的读取、编辑、转换和保存都在你的浏览器中完成，网站服务器只提供页面，不接收文件内容。
  • 本地草稿和界面偏好保存在浏览器本地存储中，只有这台电脑的这个浏览器能读到。
  • 使用「打开 FindChanged」「交给 FindChanged」时，所选内容会在浏览器中交给 FindChanged 页面（默认 https://findchanged.com）。只发送选中的节点或文档，不会修改原文件。
  • 本机助手只在本机工作，不把文件发给网站。

限制

  • XML 不支持 DTD；Schema 校验只支持一部分声明。
  • YAML 的锚点、别名和自定义标签受保护，部分操作（比较、转换）不可用。
  • 直接写回原文件只在 Edge / Chrome 等支持文件系统访问的浏览器中可用；其他浏览器保存为下载。
  • CSV、SQLite、Excel 编辑器目前只有中文界面。

常见问题

为什么点「保存」变成了下载？

当前浏览器或访问方式不能写回原文件，例如普通 HTTP 访问、离线版、非 Edge / Chrome 浏览器，或打开的是示例。可以改用 HTTPS 地址，或通过本机助手打开。

保存时提示「没有权限」？

第一次保存时浏览器会询问是否允许修改文件，请选择允许。如果之前拒绝过，重新用「打开文件」打开该文件即可再次询问。

打开后中文是乱码？

文件没有 BOM 又不是 UTF-8 时，需要在「选择文件编码」窗口中挑选正确的编码，例如 GB18030。确认预览正常后再打开。

提示文件已被其他程序修改？

打开以后，磁盘上的文件被别的程序改过。选择覆盖会用当前内容替换磁盘上的版本；选择取消则保持磁盘文件不变，你可以先导出当前内容再比较。

刷新页面后内容还在吗？

未保存的修改会在离开页面前提示。可用「保存本地草稿」做恢复备份，但它不能代替保存文件。

XJY Editor Help

XJY Editor views and edits XML, JSON and YAML documents in the browser, and adds three data editors for CSV, SQLite and Excel. This page explains the features, how saving works, and the limits.

Quick start

  1. Open XJY Editor and click Open file to choose an .xml, .json or .yaml file, or try one of the sample buttons first.
  2. Select a node in the tree on the left and edit its name, value or attributes on the right. Inside a container, the Smart table edits sibling nodes together.
  3. Click Save or press Ctrl+S. The original encoding and line endings are kept; see Saving, drafts and export.

The CSV, SQLite and Excel editor links in the header open in a new tab and leave your current work untouched.

Files are processed only in your browser and are not uploaded. See Privacy and data for the exceptions.

Opening files and encodings

Click Open file to choose a local file. The format follows the extension: .xml, .json, .yaml / .yml.

Encoding detection

  • A byte order mark decides the encoding (UTF-8, UTF-16 LE / BE).
  • An encoding named in the XML declaration (such as encoding="GBK") is used.
  • Otherwise the file is read as strict UTF-8.
  • If none of these works, the Choose the file encoding window opens. Pick an encoding and check the live preview before opening. The suggestion is Windows-1252 in the English interface and GB18030 in the Chinese one.

Files that look binary are not opened. The file status line at the bottom shows the linked file, encoding and line endings, for example “Linked file: data.xml · GB18030 · CRLF”.

Syntax errors

A file with syntax errors opens in source repair mode: fix it on the Source tab and click Apply source. The tree and table are unavailable until then. Validate syntax checks the document or the unapplied source at any time.

Browsing and editing nodes

Editing a node

Select a node in the tree; edit its name, type, attributes or value on the right. Changes apply when the field loses focus. Nodes can be added, copied, moved up or down, moved elsewhere and deleted, and you can drag them in the tree and the table to reorder.

Navigation

  • Alt+← / Alt+→ go back / forward; Alt+↑ goes to the parent.
  • Ctrl+K focuses search. Search names, values, attributes or display paths; clicking a result reveals the node.
  • The tree and the source follow each other: moving the cursor in the source selects the node, and selecting a node highlights its source.

Source

Edit text directly on the Source tab and click Apply source to update the nodes. While the source has unapplied changes, locating and node comparison pause. Format re-indents with two spaces and can be undone.

More tools

Check duplicates lists identical sibling elements in XML (report only). There are also condition queries, checkpoints, batch previews, templates and a subset of Schema validation.

Smart table

Inside a container node, the Smart table shows its children as rows: XML attributes and simple child elements, or JSON / YAML fields, become columns. Press Enter to apply a cell; fields with subtrees can be entered.

  • Use the first-column check boxes, Select filtered rows and Clear selection for batch actions.
  • After filtering, records with the same structure are recognised as columns again.
  • Dragging inside an edit box selects text; it does not move rows.
  • Similar edits in one column can start assisted editing.

Assisted editing

Assisted editing repeats the change you made in a few cells across the rest of the column. It is available in XJY Editor and in the CSV, SQLite and Excel editors.

Automatic

Make a similar insertion or deletion in three different records of one column (for example, remove a leading PRE_). After the third edit, a preview lists the other cells that would change.

On request

Click Assisted editing, or right-click a cell and choose Assist editing this column…, to choose the column, rule, text and position yourself. Shift+right-click keeps the browser menu.

Rules and scope

  • Rules are tried in order: exact match → ignore case → same length and pattern → same length only. You can pick another compatible rule or restore the first one.
  • End positions count from the right; characters are counted as Unicode code points.
  • The scope is the current filter result by default; you can switch to all records in the current folder.
  • The automatic mode does not repeat your three manual edits.

Nothing is written until you confirm the preview, and the whole batch undoes in one step.

Saving, drafts and export

Save

Every editor has a single Save button (Ctrl+S). It writes the file with the encoding, byte order mark and line endings it was opened with. Whether it writes back to the original file depends on the browser and how the file was opened:

SituationWhat Save does
Edge or Chrome over HTTPS or a local address, file opened with Open file Writes back to the original file. The browser asks for permission the first time.
File opened with the local helperWrites back to the original file.
Other browsers, plain HTTP, the offline version, or a sample Downloads a file with the same name; the download counts as saved.

The file status line tells you which applies: “Linked file: …” writes back, “Saving downloads the file · …” downloads.

Questions while saving

  • The file was changed by another program: if the file on disk changed after you opened it, you are asked before it is overwritten.
  • Mixed line endings: if the file mixes CRLF and LF, saving uses one of them throughout and asks before continuing.
  • Characters the encoding cannot store: for example an emoji in a GBK file. The affected lines are listed and nothing is written; change those characters and save again.

Source drafts

While the Source tab has unapplied changes, the button reads Save source and saves the source text itself without applying it. The CSV and Excel editors ask you to apply or discard the draft first.

Local drafts

Save local draft and Restore draft keep a copy in browser storage for recovery after an accidental close. They do not replace saving the file, and drafts belong to the current address only.

Export

Export file (XJY Editor) and Export CSV…, Export database…, Export workbook… in the table editors download a new copy. They leave the original file alone and do not clear the unsaved mark.

Convert and export

Convert and export… converts what you are editing into another format and downloads a new file. The current document does not change.

EditorWhat is convertedTargets
XJY EditorThe whole document, including unapplied sourceThe other two of XML, JSON, YAML
CSVThe whole table, including filtered-out recordsXLSX, TSV, CSV (encoding can change)
ExcelThe used range of the current sheetCSV, TSV
SQLiteAll records of the current tableCSV, TSV, XLSX

A preview lists what will change, for example XML comments are dropped and attributes become @name keys. Tick the box confirming you understand the conversion before exporting.

Conversions that are refused

  • XML with a DTD, or element and attribute names that would be invalid.
  • YAML with anchors / aliases, custom tags or several documents.
  • Duplicate keys, or nesting deeper than 200 levels.
  • Tables over one million cells, or beyond Excel's row and column limits.
  • Characters the target encoding cannot represent.

Comparing with FindChanged

Compare two nodes

  1. In the smart table, tick exactly two sibling nodes and click Compare selected pair.
  2. Check the left and right sides (you can swap them) and click Open FindChanged.
  3. FindChanged shows the differences between the two subtrees in a new tab.

Clicking a difference in FindChanged locates it back in XJY Editor: shared differences go to the right node, differences only on the left go to the left node. Compare again after changing the source.

Compare whole files

Send to FindChanged compares the baseline, the current content or another document as whole files.

Changes made in FindChanged are not written back. XML compares elements only; protected YAML structures cannot be compared yet. Each side is limited to 5 MiB and 100,000 lines; larger content is offered as a download instead.

CSV editor

Open or drop a .csv, .tsv or .txt file and confirm the encoding, delimiter and header row in Parse settings.

  • Comma, semicolon and tab delimiters; UTF-8, UTF-16 and GB18030. If the encoding cannot be detected, choose it yourself with a preview.
  • Every field is text: leading zeros, long numbers, dates and spaces are kept exactly.
  • Double-click a cell to edit in place: Enter confirms, Shift+Enter adds a line break, Esc cancels. Insert or delete rows and columns, rename headers, paste a block.
  • Drag or Shift to extend a selection, Ctrl to add cells. Copies are tab-separated and paste straight into Excel.
  • Find, filter by column, and replace in the selection or the whole table with a preview.
  • The Source tab edits the CSV text; Apply source updates the table.

Saving rewrites only the edited records; other records, the encoding and line endings stay as they were. Deleting a column also deletes its filtered-out data, and the confirmation says so.

SQLite editor

Open a .sqlite, .sqlite3, .db or .db3 database, choose a table or view on the left, and page through 100 records at a time with multi-condition filters and column sorting.

  • Double-click a field and choose the type to write: text, integer, real, NULL or BLOB (hex). Integers are exact 64-bit values, never rounded.
  • BLOB preview & file import/export: automatically detects images (PNG, JPEG, GIF, WebP, BMP, ICO, SVG) and common formats (PDF, ZIP, GZIP, JSON, XML). Images show an inline thumbnail and dimensions in the grid; click to open the inspector with Image, Hex + ASCII and UTF-8 Text views, import a local file into a BLOB cell, or export the BLOB with the detected file extension.
  • Add records (with defaults and automatic keys) and delete several rows. The database's own constraints, foreign keys and triggers apply, and a failed action is rolled back completely.
  • Import CSV: import CSV / TSV files into a new table or append to an existing table with encoding/delimiter detection, conservative type inference and single-step undo.
  • The Structure tab lists tables, views, indexes and triggers alongside their SQL definitions, and lets you create, modify or drop tables and indexes with a live SQL preview.
  • The SQL tab runs all statements (Ctrl+Enter), the statement at the cursor (Shift+Enter) or the selection; read-only queries leave no undo history, while write batches run in one transaction as a single undo step (up to 1,000 result rows displayed).

Read-only cases and limits

  • Views, virtual tables, system tables, generated columns, and tables whose rows cannot be identified uniquely are read-only in the data grid.
  • Databases in WAL mode allow read-only queries only: close the database in its own application (checkpoint) first before modifying.
  • Databases that already have foreign key errors are read-only in the data grid, but can be repaired from the SQL tab (no new foreign key errors may be introduced).

Saving writes the whole database file. Encrypted databases are not supported.

Excel editor

Open an .xlsx workbook, switch sheets, page through rows, go to an address and filter. Hidden rows and columns stay hidden unless you show them.

  • Double-click a cell to write text, a number, a boolean, a date, a formula or an error value. Text such as 001 keeps its leading zeros.
  • Pasting tab-separated text asks first and always writes text.
  • The Source tab edits the current sheet's XML; only values and formulas of existing cells may change.

Saving changes only the edited sheet; styles, charts and other sheets are kept. The browser does not calculate formulas: edited formulas are marked “needs recalculation”, so open the saved file in Excel to recalculate.

Limits

  • Legacy .xls files can be viewed and copied but not saved; save them as .xlsx in Excel first.
  • Protected sheets and workbooks with macros or signatures are read-only; only the top-left cell of a merged range can change; shared and array formula ranges are read-only.
  • Inserting or deleting whole rows or columns, formatting and renaming sheets are not supported.
  • Workbooks up to 30 MB (100 MB uncompressed); cell text up to 32,767 characters. Encrypted workbooks are not supported.

Local helper (right-click to open)

The XJY Editor helper is a small Windows program. After installing it, right-click a file in File Explorer and choose 用 XJY Editor 打开 to open it in your browser; Save then writes straight back to the file.

  • Supports .xml, .json, .yaml, .csv, .tsv, .sqlite, .sqlite3, .db, .db3, .xlsx and .xls, each in its own editor.
  • On Windows 11 the entry may be under Show more options. It appears for a single file only, not for several files or folders.
  • Double-click XJYEditorHelper.exe to install; no administrator rights are needed and default file associations do not change. Double-click the installed helper again, or use Windows Settings → Apps, to uninstall.
  • The helper works only on 127.0.0.1 and can reach only the file you chose; file contents never go through the website. Files up to 128 MiB.
  • The helper exits ten minutes after the page stops using it. Reloading the page does not relink the file; open it again from the menu.

Writing back CSV, SQLite and Excel files needs helper 0.3.0 or later; older helpers download on save instead.

Privacy and data

  • Reading, editing, converting and saving all happen in your browser. The web server only delivers the pages and never receives file contents.
  • Local drafts and interface preferences are kept in browser storage, readable only by this browser on this computer.
  • Open FindChanged and Send to FindChanged hand the chosen content to the FindChanged page in your browser (https://findchanged.com by default). Only the selected nodes or document are sent, and the original file is not changed.
  • The local helper works only on your computer and does not send files to the website.

Limits

  • XML DTDs are not supported; Schema validation covers a subset of declarations.
  • YAML anchors, aliases and custom tags are protected, and some actions (compare, convert) are unavailable for them.
  • Writing back to the original file needs a browser with file system access, such as Edge or Chrome; other browsers download on save.
  • The CSV, SQLite and Excel editors are currently available in Chinese only.

Frequently asked questions

Why does Save download a file?

This browser or address cannot write back to the original file: plain HTTP, the offline version, a browser other than Edge or Chrome, or a sample. Use the HTTPS address, or open the file with the local helper.

Saving says permission was denied

The browser asks for permission the first time you save; choose Allow. If you declined before, open the file again with Open file to be asked again.

Text looks garbled after opening

A file without a byte order mark that is not UTF-8 needs the right encoding in the Choose the file encoding window, for example GB18030 for Chinese text. Check the preview before opening.

It says the file was changed by another program

The file on disk changed after you opened it. Overwrite replaces the disk version with your content; Cancel leaves the disk file alone so you can export your content and compare first.

Is my work kept when I reload?

You are warned before leaving a page with unsaved changes. Save local draft keeps a recovery copy, but it does not replace saving the file.

XJY Editor 說明

XJY Editor 在瀏覽器中檢視與編輯 XML、JSON、YAML 文件，另提供 CSV、SQLite、Excel 三款資料編輯器。本頁說明各項功能、儲存方式與使用限制。

快速上手

  1. 開啟 XJY Editor，點擊「開啟檔案」選擇 .xml、.json 或 .yaml 檔案；也可以先點「XML 範例」等按鈕體驗。
  2. 左側目錄樹選擇節點，右側修改名稱、值或屬性；進入容器後可在「智慧表格」中批次編輯同級節點。
  3. 修改完成後點擊「儲存」或按 Ctrl+S。儲存時保留原檔案的編碼與換行字元，詳見儲存、草稿與匯出。

頁首的「CSV 編輯器」「SQLite 編輯器」「Excel 編輯器」會在新分頁中開啟對應的資料編輯器，不影響目前編輯內容。

檔案僅在你的瀏覽器中處理，不會上傳至伺服器；例外情況見隱私與資料。

開啟檔案與編碼

點擊「開啟檔案」選擇本機檔案。格式依副檔名判斷：.xml、.json、.yaml / .yml。

編碼偵測

  • 檔案帶有 BOM 時依 BOM 辨識（UTF-8、UTF-16 LE / BE）。
  • XML 宣告中註明的編碼（如 encoding="GBK"）會被採用。
  • 其餘檔案先以嚴格 UTF-8 讀取。
  • 皆無法確定時會彈出「選擇檔案編碼」視窗：從下拉選單選擇編碼，下方預覽即時顯示讀取效果，確認文字正常後再開啟。中文介面預設建議 GB18030，英文介面預設建議 Windows-1252。

看起來是二進位內容的檔案不會被開啟。開啟後，頁面底部的檔案狀態列會顯示關聯的檔名、編碼與換行字元，例如「關聯檔案：data.xml · GB18030 · CRLF」。

語法錯誤

檔案有語法錯誤時，內容會進入原始碼修復流程：在「原始碼」分頁修改並點擊「套用原始碼」，修復前無法使用樹狀檢視與表格編輯。「✓ 語法驗證」可隨時檢查目前文件或未套用的原始碼。

瀏覽與編輯節點

單節點編輯

在左側目錄樹選擇節點，右側可修改名稱、型別、屬性或值；輸入完成後移出焦點即套用。節點可新增、複製、上移 / 下移、移動與刪除，也可以在目錄樹和表格中拖曳調整順序。

導覽

  • Alt+← / Alt+→ 返回 / 前進，Alt+↑ 進入父節點。
  • Ctrl+K 聚焦搜尋框，可搜尋名稱、值、屬性或顯示路徑，點擊結果會展開並定位節點。
  • 目錄樹與原始碼雙向定位：在原始碼中移動游標會選取對應節點，反之亦然。

原始碼

「〈〉原始碼」分頁可直接編輯文字。修改後點擊「套用原始碼」才會更新節點；未套用時會暫停定位與節點比較。「⇥ 格式化」會以兩個空白縮排重新排版，且可復原。

更多工具

「⧉ 重複檢查」會列出 XML 中完全相同的同級元素（僅提示，不修改）。此外還有條件查詢、檢查點、批次預覽、範本以及 Schema 子集驗證。

智慧表格

進入容器節點後，「▦ 智慧表格」會將其同級子節點顯示為表格：XML 的屬性與簡單子元素、JSON / YAML 的欄位各自成欄。按 Enter 套用儲存格；帶有子樹的欄位可以繼續進入。

  • 首欄核取方塊支援多選，「全選篩選結果」「清除選取」用於批次操作。
  • 篩選後，結構相同的記錄會重新識別為屬性欄。
  • 在編輯框內拖曳為選取文字，不會移動列。
  • 在同一欄中進行相似修改可觸發輔助編輯。

輔助編輯

輔助編輯可將你在幾個儲存格中所做的相同修改，批次套用到同一欄的其他儲存格。XJY Editor 以及 CSV、SQLite、Excel 編輯器皆支援。

自動辨識

在同一欄中，對三筆不同記錄連續進行相似的插入或刪除（例如都刪掉開頭的 PRE_），第三次提交後會彈出預覽，列出將要修改的其餘儲存格。

主動發起

點擊「輔助編輯」，或在儲存格按右鍵選擇「輔助編輯此欄…」，自行指定欄位、規則、內容與位置。Shift+右鍵可保留瀏覽器原本的選單。

規則與範圍

  • 系統依優先順序比對規則：完全一致 → 忽略大小寫 → 等長同模式 → 僅等長。下拉清單可改選其他相容規則，也可還原初始規則。
  • 結束位置從右側起算；字元以 Unicode 碼點計算。
  • 範圍預設為目前篩選結果，可明確切換為目前目錄的全部記錄。
  • 自動模式不會重複處理你手動修改的那三筆。

檢查預覽後點擊確認才會寫入；整批修改可一次復原。

儲存、草稿與匯出

儲存

每個編輯器都只有一個「儲存」按鈕（Ctrl+S）。儲存時會依照開啟時的編碼、BOM 與換行字元寫出檔案。能否直接寫回原檔案，取決於瀏覽器與開啟方式：

情況儲存結果
Edge 或 Chrome，透過 HTTPS 或本機位址存取，並用「開啟檔案」開啟 直接寫回原檔案。第一次儲存時瀏覽器會詢問是否允許修改該檔案。
透過本機助手右鍵開啟直接寫回原檔案。
其他瀏覽器、透過一般 HTTP 存取、離線版，或開啟的是範例 下載一份同名檔案，下載即視為已儲存。

頁面底部的檔案狀態列會說明目前屬於哪種情況：「關聯檔案：…」表示寫回原檔案，「儲存時下載 · …」表示下載。

儲存時的提示

  • 檔案已被其他程式修改：開啟後磁碟上的檔案又被更動時，儲存前會詢問是否覆寫。
  • 換行字元混用：檔案中同時有 CRLF 與 LF 時，儲存會統一為其中一種，並先詢問是否繼續。
  • 字元無法以原編碼儲存：例如在 GBK 檔案中輸入了 emoji，系統會列出有問題的行且不會寫出檔案。請修改這些字元後再儲存。

原始碼草稿

原始碼分頁有未套用的修改時，按鈕會顯示為「儲存原始碼」，儲存的是原始碼文字本身，不會自動套用到節點。CSV 與 Excel 編輯器則要求先套用或捨棄原始碼草稿。

本機草稿

「儲存本機草稿」「還原草稿」會將內容保存在瀏覽器本機儲存空間，供意外關閉後還原，不能取代儲存檔案。草稿僅屬於目前網址，更換網址或使用離線版時互不相通。

匯出

「↓ 匯出檔案」（XJY Editor）以及表格編輯器中的「匯出 CSV…」「匯出資料庫…」「匯出工作簿…」會下載一份新檔案，不影響原檔案，也不會清除未儲存標記。

轉換並匯出

「轉換並匯出…」會將正在編輯的內容轉換成另一種格式並下載新檔案，目前文件維持不變。

編輯器轉換內容可轉換為
XJY Editor目前整份文件（包含未套用的原始碼）XML、JSON、YAML 中的另外兩種
CSV目前整個表格，包含因篩選而隱藏的記錄XLSX、TSV、CSV（可變更編碼）
Excel目前工作表的完整使用範圍CSV、TSV
SQLite目前資料表的全部記錄CSV、TSV、XLSX

轉換前會顯示預覽與可能發生的變化，例如 XML 轉 JSON 時註解會遺失、屬性會寫成 @名稱。需勾選「我已了解以上轉換規則與內容變化」後才能匯出。

會被拒絕的情況

  • XML 中含有 DTD，或轉換後的元素名、屬性名不合法。
  • YAML 使用錨點 / 別名、自訂標籤或多文件。
  • 有重複鍵，或巢狀深度超過 200 層。
  • 表格超過 100 萬個儲存格，或超出 Excel 的行列上限。
  • 目標編碼無法表示其中的字元。

與 FindChanged 比較

比較兩個節點

  1. 在智慧表格中勾選恰好兩個同級節點，點擊「比較選取兩項」。
  2. 確認左右順序（可互換），點擊底部「開啟 FindChanged」。
  3. FindChanged 會在新分頁中顯示兩個子樹的差異。

在 FindChanged 中點擊差異可回到 XJY Editor 定位：共有的差異回到右側節點，左側獨有的差異回到左側節點。來源內容變動後需要重新比較。

比較整個檔案

「交給 FindChanged」可比較基準版本、目前內容或另一份文件的完整檔案。

在 FindChanged 中所做的修改不會寫回 XJY Editor。XML 僅支援比較元素；YAML 參照與受保護結構暫不支援比較。單側上限為 5 MiB、10 萬行，超出時僅提供檔案下載。

CSV 編輯器

開啟或拖入 .csv、.tsv、.txt 檔案，在「解析設定」中確認編碼、分隔符號以及是否將首列作為標題列。

  • 支援逗號、分號、定位字元（Tab）分隔；編碼支援 UTF-8、UTF-16 與 GB18030，無法辨識時需手動選擇並預覽。
  • 所有欄位皆以文字處理：前導零、長數字、日期與空白皆原樣保留。
  • 按兩下儲存格即可在格內編輯：Enter 確認，Shift+Enter 換行，Esc 取消。可插入 / 刪除列與欄、修改標題、貼上矩形區域。
  • 拖曳或按 Shift 延伸選取、按 Ctrl 多選；複製內容為 Tab 分隔文字，可直接貼到 Excel。
  • 支援尋找、依欄篩選，以及在選取區或全表取代，取代前提供預覽。
  • 「原始碼」分頁可直接編輯 CSV 文字，點擊「套用原始碼」後更新表格。

儲存時僅變動編輯過的記錄，其餘記錄、編碼與換行字元保持原樣。刪除整欄會連同篩選隱藏的資料一併刪除，確認視窗會加以提示。

SQLite 編輯器

開啟 .sqlite、.sqlite3、.db、.db3 資料庫檔案，左側選擇資料表或檢視表，表格每頁顯示 100 筆，支援多條件組合篩選（包含、不包含、比較運算子、NULL 與空文字判斷）及點擊欄標排序。

  • 按兩下欄位即可編輯，並明確選擇寫入型別：文字、整數、實數、NULL 或 BLOB（十六進位）。整數以 64 位元精確處理，不會被捨入。
  • 可新增記錄（使用預設值與自動主鍵）及刪除多列。資料庫本身的條件約束、外鍵與觸發器照常生效，失敗時整個操作會回溯。
  • 匯入 CSV：可將 CSV / TSV 匯入為新資料表或附加至現有資料表，自動辨識編碼與分隔符號、推斷欄位型別並逐欄調整，一步復原。
  • 結構分頁：列出資料表、檢視表、索引與觸發器及建表 SQL；支援建立 / 修改 / 刪除資料表（優先使用 ALTER TABLE，必要時自動重建表並保留資料、索引、觸發器與自增序號）以及建立 / 刪除索引。
  • SQL 分頁：支援執行全部（Ctrl+Enter）、執行游標所在陳述式（Shift+Enter）或選取的陳述式；唯讀查詢不產生修改歷史，含寫入的整批作為單一交易與一步復原，每個結果集最多顯示前 1000 列。

唯讀與限制

  • 檢視表、虛擬表、系統表、產生欄，以及無法唯一識別記錄的資料表，無法在資料頁直接編輯。
  • WAL 模式的資料庫僅允許查詢：請先在原應用程式中關閉資料庫（完成檢查點）再修改。
  • 已有外鍵錯誤的資料庫在資料頁拒絕修改，可在「SQL」分頁修復外鍵問題（不允許產生新的外鍵錯誤）。

儲存會寫出整個資料庫檔案。暫不支援開啟加密資料庫。

Excel 編輯器

開啟 .xlsx 工作簿，切換工作表、翻頁、依位址定位與篩選。隱藏的列與欄預設不顯示，可選擇顯示。

  • 按兩下儲存格即可編輯，可寫入文字、數值、布林值、日期、公式或錯誤值。文字 001 會保留前導零。
  • 貼上 Tab 分隔文字前會先確認，內容一律以文字寫入。
  • 「原始碼」分頁可編輯目前工作表的 XML，僅允許修改既有儲存格的值與公式。

儲存時僅修改目標工作表，原有樣式、圖表及其他工作表皆會保留。瀏覽器不計算公式：修改後的公式會標記為「待重算」，請在 Excel 中開啟儲存後的檔案完成重算。

限制

  • .xls 舊格式僅能檢視與複製，無法儲存；請先在 Excel 中另存為 .xlsx。
  • 受保護的工作表、含巨集或簽章的工作簿為唯讀；合併儲存格區域僅能修改左上角；共用公式與陣列公式區域為唯讀。
  • 不支援插入 / 刪除整列整欄、修改格式或重新命名工作表。
  • 工作簿上限 30 MB，解壓縮後上限 100 MB；儲存格文字最多 32,767 個字元。不支援加密工作簿。

XJY Editor 助手是一個 Windows 小程式。安裝後，在檔案總管中對檔案按右鍵，選擇「用 XJY Editor 打开」，即可在瀏覽器中開啟該檔案，儲存時直接寫回原檔案。

  • 支援 .xml、.json、.yaml、.csv、.tsv、.sqlite、.sqlite3、.db、.db3、.xlsx、.xls，依格式進入對應的編輯器。
  • 在 Windows 11 中，此選項可能位於「顯示其他選項」裡。僅對單一檔案顯示，多選或資料夾不會顯示。

常見問題

為什麼點「儲存」變成了下載？

目前的瀏覽器或存取方式無法寫回原檔案，例如一般 HTTP 存取、離線版、非 Edge / Chrome 瀏覽器，或開啟的是範例。可以改用 HTTPS 位址，或透過本機助手開啟。

儲存時提示「沒有權限」？

第一次儲存時瀏覽器會詢問是否允許修改檔案，請選擇允許。如果先前曾拒絕過，重新使用「開啟檔案」開啟該檔案即可再次詢問。

開啟後中文變亂碼？

檔案沒有 BOM 又不是 UTF-8 時，需要在「選擇檔案編碼」視窗中挑選正確的編碼，例如 GB18030 或 Big5。確認預覽正常後再開啟。

提示檔案已被其他程式修改？

開啟以後，磁碟上的檔案被其他程式更動過。選擇覆寫會以目前內容取代磁碟上的版本；選擇取消則保持磁碟檔案不變，你可以先匯出目前內容再比較。

重新整理頁面後內容還在嗎？

有未儲存的修改時，離開頁面前會先提示。可用「儲存本機草稿」做還原備份，但它不能取代儲存檔案。

XJY Editor ヘルプ

XJY Editor はブラウザー上で XML、JSON、YAML ドキュメントを閲覧・編集でき、さらに CSV、SQLite、Excel 用の 3 つのデータエディターを備えています。このページでは各機能、保存方法、および制限事項について説明します。

クイックスタート

  1. XJY Editor を開き、「ファイルを開く」をクリックして .xml、.json、または .yaml ファイルを選択します。まずは「XML サンプル」などのボタンでお試しいただくこともできます。
  2. 左側のツリーでノードを選択し、右側で名前、値、属性を編集します。コンテナー内に入ると、「スマートテーブル」で兄弟ノードを一括編集できます。
  3. 編集が終わったら「保存」をクリックするか、Ctrl+S を押します。元のファイルの文字コードと改行コードは保持されます。詳しくは保存、下書き、エクスポートをご覧ください。

ヘッダーの「CSV」「SQLite」「Excel」リンクは対応するデータエディターを新しいタブで開きます。現在編集中の内容には影響しません。

ファイルはブラウザー内でのみ処理され、サーバーへアップロードされることはありません。例外についてはプライバシーとデータをご覧ください。

ファイルを開く・文字コード

「ファイルを開く」をクリックしてローカルファイルを選択します。形式は拡張子で判定されます：.xml、.json、.yaml / .yml。

文字コードの自動判定

  • BOM が付いている場合は BOM に従って判定されます（UTF-8、UTF-16 LE / BE）。
  • XML 宣言に記述された文字コード（例：encoding="GBK"）が採用されます。
  • それ以外のファイルはまず厳密な UTF-8 として読み込みます。
  • いずれでも確定できない場合は「ファイルの文字コードを選択」ウィンドウが開きます。ドロップダウンから文字コードを選び、下のリアルタイムプレビューで文字化けがないことを確認してから開いてください。中国語 UI では GB18030、英語 UI では Windows-1252 が初期候補として提案されます。

バイナリファイルと判断されたファイルは開けません。開いた後は、ページ下部のステータス行にリンクされたファイル名、文字コード、改行コードが表示されます（例：「リンク済みファイル：data.xml · GB18030 · CRLF」）。

構文エラー

構文エラーのあるファイルはソース修復モードで開きます。「ソース」タブで修正して「ソースを適用」をクリックするまで、ツリーやテーブルでの編集はできません。「✓ 構文チェック」では、現在のドキュメントや未適用のソースをいつでも検証できます。

ノードの閲覧と編集

単一ノードの編集

左側のツリーでノードを選択すると、右側で名前、型、属性、値を変更できます。入力後にフォーカスを外すと変更が適用されます。ノードの追加、複製、上下移動、別の場所への移動、削除が可能で、ツリーやテーブル上でドラッグして並び替えることもできます。

ナビゲーション

  • Alt+← / Alt+→ で戻る / 進む、Alt+↑ で親ノードへ移動します。
  • Ctrl+K で検索ボックスにフォーカスします。名前、値、属性、表示パスを検索でき、結果をクリックすると該当ノードを展開して表示します。
  • ツリーとソースの双方向連動：ソース内でカーソルを動かすと対応するノードが選択され、ノードを選択するとソースの該当箇所がハイライトされます。

ソース

「〈〉ソース」タブではテキストを直接編集できます。変更後に「ソースを適用」をクリックするとノードが更新されます。未適用の変更がある間は、位置連動とノード比較が一時停止されます。「⇥ フォーマット」はスペース 2 個のインデントで整形し、元に戻すこともできます。

その他のツール

「⧉ 重複チェック」は XML 内の完全に一致する兄弟要素を一覧表示します（通知のみで変更は行いません）。このほか、条件検索、チェックポイント、一括プレビュー、テンプレート、Schema サブセット検証も利用できます。

スマートテーブル

コンテナーノードに入ると、「▦ スマートテーブル」が子ノードを一覧表として表示します。XML の属性や単純な子要素、JSON / YAML のフィールドがそれぞれ列になります。Enter でセルの変更を確定でき、サブツリーを持つフィールドはさらに中へ入れます。

  • 先頭列のチェックボックスで複数選択でき、「フィルター結果をすべて選択」「選択を解除」で一括操作を行えます。
  • フィルター適用後、構造が同じレコードは再び属性列として認識されます。
  • 編集ボックス内でのドラッグはテキスト選択となり、行の移動にはなりません。
  • 同じ列で似た編集を行うとアシスト編集が起動することがあります。

アシスト編集

アシスト編集は、いくつかのセルで行った同じような変更を、同じ列の他のセルにも一括適用する機能です。XJY Editor および CSV、SQLite、Excel エディターで利用できます。

自動認識

同じ列の異なる 3 つのレコードに対して連続で似た挿入や削除を行うと（例：先頭の PRE_ を削除する）、3 回目の確定後にプレビューが表示され、変更対象となる残りのセルが一覧表示されます。

手動実行

「アシスト編集」をクリックするか、セルを右クリックして「この列をアシスト編集…」を選ぶと、列・ルール・内容・位置を自分で指定できます。Shift+右クリックでブラウザー標準のメニューを表示できます。

ルールと範囲

  • ルールは優先順に照合されます：完全一致 → 大文字・小文字を区別しない → 同じ長さ・同じパターン → 同じ長さのみ。ドロップダウンから他の互換ルールを選んだり、初期ルールに戻したりできます。
  • 終了位置は右端から数えます。文字数は Unicode コードポイント単位でカウントされます。
  • 対象範囲は初期設定では現在のフィルター結果ですが、現在のフォルダーの全レコードへ明示的に切り替えることもできます。
  • 自動モードでは、手動で編集した 3 件を重複して処理することはありません。

プレビューを確認して確定するまで書き込みは行われません。一括変更は 1 回の操作でまとめて元に戻せます。

保存、下書き、エクスポート

保存

各エディターの保存ボタンは「保存」（Ctrl+S）の 1 つだけです。開いたときの文字コード、BOM、改行コードを維持して書き出します。元のファイルへ直接上書き保存できるかどうかは、ブラウザーと開き方によって異なります：

状況保存時の動作
Edge または Chrome で HTTPS またはローカルアドレス経由でアクセスし、「ファイルを開く」から開いた場合 元のファイルに直接上書き保存します。初回保存時にブラウザーから変更許可の確認が表示されます。
ローカルヘルパーの右クリックメニューから開いた場合元のファイルに直接上書き保存します。
その他のブラウザー、通常の HTTP アクセス、オフライン版、またはサンプルを開いた場合 同名ファイルをダウンロードします。ダウンロードをもって保存完了とみなされます。

ページ下部のステータス行に現在の方式が表示されます：「リンク済みファイル：…」は直接上書き、「保存時にダウンロード · …」はダウンロードを意味します。

保存時の確認メッセージ

  • 他のプログラムによってファイルが変更されました：開いた後にディスク上のファイルが変更されていた場合、上書き前に確認が表示されます。
  • 改行コードの混在：ファイル内に CRLF と LF が混在している場合、保存時にどちらか一方へ統一するため続行確認が表示されます。
  • 元の文字コードで保存できない文字：例として GBK ファイルに絵文字を入力した場合など、該当行が一覧表示され書き出しは中止されます。文字を修正してから再度保存してください。

ソース下書き

ソースタブに未適用の変更がある場合、ボタンは「ソースを保存」に変わり、ノードへ適用せずソーステキストをそのまま保存します。CSV および Excel エディターでは、先にソース下書きを適用または破棄する必要があります。

ローカル下書き

「ローカル下書きを保存」「下書きを復元」は、誤ってタブを閉じた際の復旧用にブラウザーのローカルストレージへ保存します。ファイル保存の代わりにはなりません。下書きは現在の URL ごとに管理され、別の URL やオフライン版とは共有されません。

エクスポート

「↓ ファイルをエクスポート」（XJY Editor）や、テーブルエディターの「CSV をエクスポート…」「データベースをエクスポート…」「ブックをエクスポート…」は新しいファイルをダウンロードします。元のファイルには影響せず、未保存マークも消えません。

変換してエクスポート

「変換してエクスポート…」は編集中の内容を別の形式に変換して新しいファイルとしてダウンロードします。現在のドキュメントは変更されません。

エディター変換対象変換先形式
XJY Editor現在のドキュメント全体（未適用のソースを含む）XML、JSON、YAML のうち他の 2 形式
CSVテーブル全体（フィルターで非表示のレコードを含む）XLSX、TSV、CSV（文字コード変更可）
Excel現在のシートの使用範囲全体CSV、TSV
SQLite現在のテーブルの全レコードCSV、TSV、XLSX

変換前にプレビューと変更点が表示されます（例：XML から JSON への変換ではコメントが失われ、属性は @名前 キーになります）。「上記の変換ルールと内容の変化を理解しました」にチェックを入れてからエクスポートしてください。

変換が拒否されるケース

  • XML に DTD が含まれている、または変換後の要素名・属性名が無効になる場合。
  • YAML でアンカー / エイリアス、カスタムタグ、複数ドキュメントを使用している場合。
  • 重複キーがある、またはネストが 200 階層を超える場合。
  • テーブルが 100 万セルを超える、または Excel の行・列の上限を超える場合。
  • 変換先の文字コードで表現できない文字が含まれている場合。

FindChanged で比較

2 つのノードを比較

  1. スマートテーブルで兄弟ノードをちょうど 2 つチェックし、「選択した 2 件を比較」をクリックします。
  2. 左右の順序を確認し（入れ替え可能）、下部の「FindChanged を開く」をクリックします。
  3. FindChanged が新しいタブで 2 つのサブツリーの差分を表示します。

FindChanged 上で差分をクリックすると XJY Editor に戻って該当箇所へ移動します。共通の差分は右側のノードへ、左側のみの差分は左側のノードへ移動します。元の内容を変更した場合は再度比較してください。

ファイル全体を比較

「FindChanged に送る」では、ベースライン、現在の内容、または別のドキュメントをファイル全体として比較できます。

FindChanged で行った編集は XJY Editor には書き戻されません。XML は要素のみ比較可能です。YAML の参照や保護された構造は現在比較できません。片側あたり最大 5 MiB、10 万行までで、超過時はファイルダウンロードのみ提供されます。

CSV エディター

.csv、.tsv、.txt ファイルを開くかドロップし、「解析設定」で文字コード、区切り文字、先頭行をヘッダーとするかを確認します。

  • カンマ、セミコロン、タブ区切りに対応。文字コードは UTF-8、UTF-16、GB18030 に対応し、自動判定できない場合はプレビューを見ながら手動選択できます。
  • すべてのフィールドはテキストとして扱われます：先頭のゼロ、長い数値、日付、空白もそのまま保持されます。
  • セルをダブルクリックしてインライン編集：Enter で確定、Shift+Enter で改行、Esc でキャンセル。行・列の挿入 / 削除、ヘッダー変更、矩形範囲の貼り付けに対応します。
  • ドラッグや Shift で範囲拡張、Ctrl で複数選択。コピー内容はタブ区切りテキストになり、そのまま Excel に貼り付けられます。
  • 検索、列ごとのフィルター、選択範囲またはテーブル全体の置換（置換前プレビュー付き）に対応します。
  • 「ソース」タブで CSV テキストを直接編集し、「ソースを適用」でテーブルを更新できます。

保存時は編集したレコードのみが更新され、他のレコード、文字コード、改行コードは元のまま維持されます。列を削除するとフィルターで非表示になっているデータも一緒に削除され、確認ダイアログが表示されます。

SQLite エディター

.sqlite、.sqlite3、.db、.db3 データベースファイルを開き、左側でテーブルまたはビューを選択します。1 ページあたり 100 件表示され、複数条件の組み合わせフィルター（含む、含まない、比較演算子、NULL および空文字判定）と列ヘッダークリックでの並び替えに対応します。

  • フィールドをダブルクリックして編集し、書き込む型（テキスト、整数、実数、NULL、または 16 進数の BLOB）を明示的に指定します。整数は 64 ビット精度で正確に処理され、丸められません。
  • レコードの追加（デフォルト値や自動主キーに対応）と複数行の削除が可能です。データベース本来の制約、外部キー、トリガーが有効になり、失敗時は操作全体がロールバックされます。
  • CSV インポート：CSV / TSV を新規テーブルとしてインポート、または既存テーブルに追加できます。文字コード・区切り文字の自動判定、列ごとの型推論と調整、1 ステップでの取り消しに対応します。
  • 構造タブ：テーブル、ビュー、インデックス、トリガーと作成 SQL を一覧表示します。テーブルの作成 / 変更 / 削除（ALTER TABLE を優先し、必要に応じてデータ・インデックス・トリガー・自動増分値を保持したまま自動再構築）およびインデックスの作成 / 削除に対応します。
  • SQL タブ：すべて実行（Ctrl+Enter）、カーソル位置の文を実行（Shift+Enter）、選択範囲を実行できます。読み取り専用クエリは変更履歴を残さず、書き込みを含むバッチは 1 つのトランザクションおよび 1 回の取り消し単位として実行されます（各結果セットは最大 1,000 行まで表示）。

読み取り専用と制限事項

  • ビュー、仮想テーブル、システムテーブル、生成列、および行を一意に特定できないテーブルはデータタブから直接編集できません。
  • WAL モードのデータベースは読み取りクエリのみ可能です。編集前に元のアプリケーションでデータベースを閉じてチェックポイントを完了してください。
  • すでに外部キーエラーが存在するデータベースはデータタブでの変更が拒否されます。「SQL」タブから修復できます（新たな外部キーエラーの発生は許可されません）。

保存時はデータベースファイル全体を書き出します。暗号化されたデータベースは現在サポートされていません。

Excel エディター

.xlsx ブックを開き、シートの切り替え、ページ送り、アドレス指定での移動、フィルターを行えます。非表示の行・列は初期状態では隠れていますが、表示に切り替えることができます。

  • セルをダブルクリックして、テキスト、数値、真偽値、日付、数式、またはエラー値を入力できます。テキスト 001 は先頭のゼロを保持します。
  • タブ区切りテキストの貼り付け時は確認が表示され、内容はすべてテキストとして書き込まれます。
  • 「ソース」タブで現在のシートの XML を編集できます。既存セルの値と数式の変更のみ許可されます。

保存時は編集対象のシートのみが更新され、元のスタイル、グラフ、その他のシートは保持されます。ブラウザー上では数式を計算しないため、編集した数式には「再計算が必要」マークが付きます。保存後のファイルを Excel で開いて再計算してください。

制限事項

  • 旧形式の .xls ファイルは閲覧とコピーのみで保存できません。先に Excel で .xlsx として保存してください。
  • 保護されたシート、マクロや署名を含むブックは読み取り専用です。結合セルは左上のセルのみ変更でき、共有数式や配列数式の範囲は読み取り専用です。
  • 行・列全体の挿入 / 削除、書式設定の変更、シート名の変更はできません。
  • ブックの最大サイズは 30 MB（展開後最大 100 MB）、セルのテキストは最大 32,767 文字までです。暗号化されたブックはサポートされていません。

ローカルヘルパー（右クリックで開く）

XJY Editor ヘルパーは Windows 向けの小型ユーティリティです。インストールすると、エクスプローラーでファイルを右クリックして「用 XJY Editor 打开」を選ぶだけでブラウザーで開け、保存時に元のファイルへ直接上書きできます。

  • .xml、.json、.yaml、.csv、.tsv、.sqlite、.sqlite3、.db、.db3、.xlsx、.xls に対応し、形式ごとのエディターで開きます。
  • Windows 11 では「その他のオプションを表示」内に表示される場合があります。単一ファイルに対してのみ表示され、複数選択やフォルダーには表示されません。
  • XJYEditorHelper.exe をダブルクリックしてインストールします。管理者権限は不要で、ファイルの既定の関連付けも変更されません。アンインストールはインストール先の実行ファイルを再度ダブルクリックするか、Windows の「設定 → アプリ」から行えます。
  • ヘルパーはローカルの 127.0.0.1 のみで動作し、選択した 1 つのファイルにのみアクセスできます。ファイル内容がウェブサイトサーバーを経由することはありません。単一ファイルの最大サイズは 128 MiB です。
  • ページの使用が止まってから 10 分後にヘルパーは自動終了します。ページを再読み込みしてもファイルのリンクは自動復帰しないため、右クリックから開き直してください。

CSV、SQLite、Excel ファイルの直接上書き保存にはヘルパー 0.3.0 以降が必要です。旧バージョンでは保存時にダウンロードになります。

プライバシーとデータ

  • ファイルの読み込み、編集、変換、保存はすべてブラウザー内で完結します。ウェブサーバーはページを配信するだけで、ファイル内容を受け取ることはありません。
  • ローカル下書きや UI 設定はブラウザーのローカルストレージに保存され、このパソコンのこのブラウザーからのみ読み取れます。
  • 「FindChanged を開く」「FindChanged に送る」を使うと、選択した内容がブラウザー内で FindChanged ページ（既定は https://findchanged.com）へ渡されます。送信されるのは選択したノードまたはドキュメントのみで、元のファイルは変更されません。
  • ローカルヘルパーはローカル PC 内のみで動作し、ファイルをウェブサイトへ送信しません。

制限事項

  • XML の DTD はサポートされていません。Schema 検証は一部の宣言のみ対応しています。
  • YAML のアンカー、エイリアス、カスタムタグは保護されており、一部の操作（比較、変換）は利用できません。
  • 元のファイルへの直接上書き保存は、Edge / Chrome などファイルシステムアクセスに対応したブラウザーでのみ利用できます。その他のブラウザーではダウンロード保存になります。
  • CSV、SQLite、Excel エディターは現在中国語インターフェースのみ対応しています。

よくある質問

「保存」を押すとダウンロードになるのはなぜですか？

現在のブラウザーやアクセス方法では元のファイルへ直接書き戻せないためです（通常の HTTP アクセス、オフライン版、Edge / Chrome 以外のブラウザー、またはサンプルを開いている場合など）。HTTPS アドレスを利用するか、ローカルヘルパーから開いてください。

保存時に「権限がありません」と表示されます

初回保存時にブラウザーからファイル変更の許可を求められますので、「許可」を選択してください。以前に拒否した場合は、「ファイルを開く」から再度ファイルを開き直すと再び確認が表示されます。

ファイルを開くと文字化けします

BOM がなく UTF-8 でもないファイルの場合は、「ファイルの文字コードを選択」ウィンドウで適切な文字コード（例：Shift_JIS や GB18030）を選び、プレビューが正しく表示されることを確認してから開いてください。

「他のプログラムによってファイルが変更されました」と表示されます

ファイルを開いた後に、ディスク上のファイルが別のプログラムで更新されています。「上書き」を選ぶと現在の内容でディスク上のファイルを置き換えます。「キャンセル」を選ぶとディスク上のファイルは維持されるため、先に現在の内容をエクスポートして比較できます。

ページを再読み込みしても編集内容は残りますか？

未保存の変更がある場合は、ページを離れる前に確認が表示されます。復旧用バックアップとして「ローカル下書きを保存」を利用できますが、ファイル保存の代わりにはなりません。
